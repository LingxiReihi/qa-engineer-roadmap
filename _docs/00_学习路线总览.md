## 一、目标画像：什么叫「测试开发」？

测试开发（SDET，Software Development Engineer in Test）≠ 测试工程师，更 ≠ 点点点。

| 角色 | 核心能力 | 主要产出 |
|---|---|---|
| 测试执行 | 按用例点鼠标 | 测试报告、Bug 单 |
| 测试工程师 | 写用例、做接口测试 | 测试用例库、自动化脚本 |
| **测试开发** | **用代码搭框架、写工具、做平台** | **测试框架、平台、CI 流水线、性能工具** |

测试开发 = **60% 后端开发能力 + 40% 测试专业能力 + 工程化思维**。

本路径的目标就是把你从「会 Python」训练成「能用 Python 做测试开发」。

## 四、8 个阶段一览

### 阶段 01 · Python 语言基础（测试视角）— 3 周
**核心产出**：能读懂业务代码，能写带类型注解的小工具，理解装饰器/生成器/上下文管理器的用途。
**验收标志**：用 pytest 给一个 50 行的模块写单元测试，覆盖率 > 80%。

### 阶段 02 · 测试理论与用例设计 — 2 周
**核心产出**：拿到需求文档能写出结构化用例，会用等价类、边界值、场景法、错误推测。
**验收标志**：为「登录功能」写出 30+ 条用例，覆盖正常/异常/边界/安全。

### 阶段 03 · pytest 核心与进阶 — 4 周
**核心产出**：掌握 fixture、parametrize、conftest、hook、Mock、标记、插件、报告。
**验收标志**：用 pytest + Allure 给一个小模块输出漂亮的测试报告。

### 阶段 04 · 接口自动化测试 — 4 周
**核心产出**：用 requests + pytest 写接口自动化，支持鉴权、数据驱动、参数化、Token 刷新。
**验收标志**：为一个真实 API 写 20+ 用例，含正向/反向/边界/安全用例。

### 阶段 05 · Web 与移动端自动化 — 3 ~ 4 周
**核心产出**：用 Playwright 写 Web 自动化（推荐），了解 Appium 移动端。
**验收标志**：完成一个「登录 → 搜索 → 下单 → 登出」的端到端流程。

### 阶段 06 · 性能测试与监控 — 2 周
**核心产出**：用 Locust 写压测脚本，读懂 P95/P99、吞吐、错误率。
**验收标志**：对一个接口完成压测，输出含图表的报告，能解释关键指标。

### 阶段 07 · CI/CD 与工程化 — 3 周
**核心产出**：Git 分支策略、GitHub Actions 跑测试、Docker 容器化、Allure 报告集成。
**验收标志**：推 PR 后自动触发测试，失败自动通知。

### 阶段 08 · 测试开发进阶 + 项目实战 — 6 ~ 8 周
**核心产出**：设计分层测试框架、Mock 服务、覆盖率门禁、答辩作品。
**验收标志**：有一个完整可演示的测试项目（GitHub 链接 + 报告）。

### 阶段 09 · 附录（持续使用）
学习资源、面试题清单、简历模板、常见踩坑合集。

## 七、本路径不会涉及（但你需要知道）

以下内容本路径**不深入讲**，但你应该知道它们的存在：

- **算法与数据结构**：测试开发岗位一般不要求，但基础复杂度要懂（O(n)、二分查找）。
- **前端开发**：除非你要做前端测试工具，否则了解 DOM 即可。
- **移动端原生开发**：Appium 足够，不需要学 Android/iOS 原生。
- **大数据 / AI**：不是测试开发核心，可作为长期兴趣。

> 不要因为这些没学就焦虑。**先把主线走完**。
