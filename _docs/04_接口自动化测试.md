## 四、关键知识点

### 4.1 HTTP 方法

| 方法 | 用途 | 幂等 | 安全 |
|---|---|---|---|
| GET | 获取资源 | ✅ | ✅ |
| POST | 创建资源 | ❌ | ❌ |
| PUT | 替换资源 | ✅ | ❌ |
| PATCH | 部分更新 | ❌ | ❌ |
| DELETE | 删除资源 | ✅ | ❌ |
| HEAD | 只取响应头 | ✅ | ✅ |
| OPTIONS | 查询支持的方法 | ✅ | ✅ |

### 4.2 常用状态码

- **200** OK
- **201** Created
- **204** No Content
- **301/302** 重定向
- **400** Bad Request（参数错误）
- **401** Unauthorized（未认证）
- **403** Forbidden（无权限）
- **404** Not Found
- **405** Method Not Allowed
- **409** Conflict（资源冲突）
- **422** Unprocessable Entity
- **429** Too Many Requests
- **500** Internal Server Error
- **502/503/504** Gateway / Unavailable / Timeout

### T4-12：Token 刷新

**任务**：实现一个"Token 刷新"装饰器。

```python
import requests
import functools
import time

class AuthClient:
    def __init__(self, base_url: str):
        self.base_url = base_url
        self.token = None
        self.refresh_token = None

    def login(self, username: str, password: str):
        resp = requests.post(
            f"{self.base_url}/login",
            json={"username": username, "password": password},
        )
        self.token = resp.json()["token"]
        self.refresh_token = resp.json()["refresh_token"]

    def refresh(self):
        resp = requests.post(
            f"{self.base_url}/refresh",
            json={"refresh_token": self.refresh_token},
        )
        self.token = resp.json()["token"]

    def request(self, method: str, path: str, **kwargs):
        kwargs.setdefault("timeout", 5)
        headers = kwargs.pop("headers", {})
        headers["Authorization"] = f"Bearer {self.token}"

        resp = requests.request(method, f"{self.base_url}{path}", headers=headers, **kwargs)

        if resp.status_code == 401:
            self.refresh()
            headers["Authorization"] = f"Bearer {self.token}"
            resp = requests.request(method, f"{self.base_url}{path}", headers=headers, **kwargs)

        return resp
```

**验收**：理解 Token 刷新流程。

### T4-19：测试数据管理

```python
from dataclasses import dataclass, field
from typing import List
from faker import Faker

fake = Faker()

@dataclass
class UserFactory:
    name: str = field(default_factory=fake.name)
    email: str = field(default_factory=fake.email)
    age: int = field(default_factory=lambda: fake.random_int(min=18, max=60))
    active: bool = True

    @classmethod
    def create(cls, **kwargs):
        return cls(**kwargs)

    def build(self) -> dict:
        return {
            "name": self.name,
            "email": self.email,
            "age": self.age,
            "active": self.active,
        }

# 用法

data = user.build()
```

## 七、常见陷阱

| 陷阱 | 说明 | 解决 |
|---|---|---|
| 测试顺序依赖 | 测试 A 创建的订单影响测试 B | 用 fixture 清理，或测试隔离 |
| Token 过期 | 长测试中 Token 失效 | 用 session scope + 自动刷新 |
| 硬编码 URL | 环境切换困难 | 用环境变量或配置 |
| 浮点比较 | 金额、坐标 | 用 `pytest.approx` 或转整数 |
| 时区 | 时间戳比较 | 统一用 UTC |
| 数据污染 | 测试数据写进真实数据库 | 用 Mock 或测试库 |
| 网络抖动 | 间歇性失败 | 用重试或 Mock |
| 未关闭 session | 资源泄漏 | 用 `with requests.Session()` 或 fixture yield |
