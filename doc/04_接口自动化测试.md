## 一、阶段概述

接口测试是自动化测试的核心。本阶段从"能用 requests 发请求"到"能写完整的接口测试框架"。

---

## 二、核心能力目标

- [ ] 用 requests 写接口测试（GET/POST/PUT/DELETE）
- [ ] 处理鉴权与 Token（JWT / OAuth2）
- [ ] 用 Mock 替换外部依赖（responses / requests-mock）
- [ ] 基于 OpenAPI 契约测试验证响应 schema
- [ ] 实现数据驱动与工程模式
- [ ] 用 SQL 准备/验证/清理测试数据
