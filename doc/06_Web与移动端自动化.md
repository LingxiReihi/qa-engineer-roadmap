# 06 · Web 与移动端自动化

> **阶段时长**：3 周（预计 Day 105~117）
> **前置**：阶段 04（接口自动化）验收通过

> **状态**：⏳ 待开始（到达此阶段时完善详细计划）

## 一、阶段概述

Web 自动化是测试开发的"前端能力"。本阶段从"能定位元素"到"能写完整的 Web 自动化框架"。

- [ ] 用 Playwright 写 Web 自动化（推荐）

- [ ] 完成"登录 → 搜索 → 下单 → 登出"端到端流程
