## 三、最终作品：QA Automation Platform

```text
qa-automation-platform/
├── api/              # 接口测试客户端 + 端点
├── web/              # 页面对象 + 组件
├── tests/            # api/ web/ database/ 分层测试
├── data/             # 测试数据
├── config/           # 配置管理
├── utils/            # 工具函数
├── logs/             # 日志
├── reports/          # 报告
├── conftest.py       # pytest 配置
├── pytest.ini        # pytest 配置
├── requirements.txt  # 依赖
├── Dockerfile        # 容器化
├── docker-compose.yml # 编排
└── README.md         # 文档
```

**最终 CI 流水线**：
```
git push → GitHub Actions → 启动测试环境 → 运行 Pytest
→ API 测试 → Web 测试 → 数据库验证 → 生成报告 → 测试结果
```
